# Тема Inweb для Claude

Тема для застосунку Claude (вкладка Code) у кольорах брендбука Inweb 2026: чорна основа, лаймові акценти, зелене світіння.

На фоні анімована сцена "Зростання": графік, який сам домальовується, мережа з імпульсами, стовпчики, перспективна сітка і логотип Inweb. Є дві розкладки: по центру, щоб усе було видно з відкритими боковими панелями, і широка, по краях вікна. Ще є спокійніший варіант з повільними відблисками.

## Встановлення

**Найпростіше:** оновіть застосунок Claude до останньої версії, відкрийте вкладку Code і напишіть Claude:

```
Встанови тему з https://github.com/vbaadzhy-sys/inweb-claude-theme
```

Коли Claude попросить дозвіл виконати команду, дозвольте. Потім відкрийте нову сесію, тема з'явиться після першого повідомлення.

**Вручну:**

1. Оновіть застосунок Claude до останньої версії, без цього тема не запрацює.
2. Відкрийте вкладку Code.
3. Натисніть + біля поля вводу, далі Plugins, потім Add marketplace.
4. Вставте `vbaadzhy-sys/inweb-claude-theme`
5. Натисніть Add plugin і виберіть `inweb-theme`.

Тема з'явиться в новій сесії після першого повідомлення. Поки що теми працюють лише в локальних сесіях застосунку, у хмарних їх ще нема.

**Якщо працюєте в терміналі, в сесії Claude Code:**

```
/plugin install inweb-theme --marketplace vbaadzhy-sys/inweb-claude-theme
```

На питання "Add marketplace?" відповісти `y`, потім Enter. Фон при цьому малюється лише в застосунку Claude, у звичайному терміналі його не видно.

## Команди

- `/inweb-theme` вмикає сцену "Зростання" по центру, її видно і з відкритими боковими панелями
- `/inweb-theme wide` вмикає широку розкладку по краях вікна, для роботи без бокових панелей
- `/inweb-theme calm` вмикає спокійні відблиски
- `/inweb-theme off` вимикає тему

Якщо в macOS увімкнено "Зменшити рух", анімація зупиняється і лишається нерухома картинка.

## Оновлення теми

Якщо тема вже встановлена, а на GitHub вийшла нова версія, з командного рядка:

```bash
claude plugin update inweb-theme@inweb-local
```

Потім у сесії наберіть `/reload-plugins`. Або просто видаліть плагін у застосунку і додайте його знову тими самими кроками, що вище.

## Що потрібно

Застосунок Claude з Claude Code версії 2.1.319 або новішої.

Тема лише малює кольори і фон: нічого не читає, нікуди не надсилає і нічого не зберігає.
