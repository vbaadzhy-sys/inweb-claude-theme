# Тема Inweb для Claude

Тема для застосунку Claude (вкладка Code) у кольорах брендбука Inweb 2026: чорна основа, лаймові акценти, зелене світіння.

На фоні анімована сцена "Зростання": графік, який сам домальовується, мережа з імпульсами, стовпчики, перспективна сітка і логотип Inweb у лівому верхньому куті. Є і спокійніший варіант з повільними відблисками.

## Встановлення

**У застосунку Claude:** натисни + біля поля вводу, далі Plugins, Add marketplace, встав `vbaadzhy-sys/inweb-claude-theme`, потім Add plugin і вибери `inweb-theme`.

**У терміналі, в сесії Claude Code:**

```
/plugin install inweb-theme --marketplace vbaadzhy-sys/inweb-claude-theme
```

На питання "Add marketplace?" відповісти `y`, потім Enter.

**Або з командного рядка:**

```bash
claude plugin install inweb-theme --marketplace vbaadzhy-sys/inweb-claude-theme
```

Тема вмикається сама в кожній новій сесії, а в новій сесії з'являється після першого повідомлення.

## Команди

- `/inweb-theme` вмикає сцену "Зростання"
- `/inweb-theme calm` вмикає спокійні відблиски
- `/inweb-theme off` вимикає тему

Якщо в macOS увімкнено "Зменшити рух", анімація зупиняється і лишається нерухома картинка.

## Що потрібно

Застосунок Claude з Claude Code версії 2.1.319 або новішої. У звичайному терміналі фон не малюється.

Тема лише малює кольори і фон: нічого не читає, нікуди не надсилає і нічого не зберігає.
